## Decisions
- Bufferbloat grade keyed on **absolute added latency (ms)** (Waveform/DSLReports scale),
  not the existing loaded/idle multiplier — the multiplier unfairly penalizes
  low-latency links. Both the grade and the older "Severe/…" severity label coexist.
- Privacy exclusion done at the **model (Codable) level**, not export-only — strongest /
  defense-in-depth. Trade-off: historical results no longer retain IP/DNS/gateway/SSID
  after relaunch (decode as nil); live + current-session display unaffected.
- Connection metadata (gateway/DNS/MTU/VPN/proxy) is **persisted** in `NetworkMetadata`;
  the public IP and dual-stack badge remain **live-only** (network-dependent).
- `RESEARCH_iOS_VERSION.md` (iOS-port feasibility study): **merged into main** and the
  source branch deleted (initially kept, then merged once its value was confirmed).
